# Universität Nordlicht – KI-Demo-Website

Fiktive Universitäts-Website als Showcase: „Was ist heute mit KI möglich?“
Reines HTML/CSS/JS ohne Build-Schritt und ohne Abhängigkeiten.

**Ansehen:** `index.html` im Browser öffnen (oder `python3 -m http.server` im Ordner).

- **3D:** schwebender Glas-Würfel, Orbit-Animation, Globus, isometrische Campus-Karte (CSS-3D), Partikelnetz im Hero (Canvas), Maus-Tilt der Karten
- **Barrierefreiheit:** Skip-Link, Landmarken, Tastaturbedienung, `prefers-reduced-motion`, Funktion ohne JavaScript
- **Responsiv:** 320 px bis 1920 px

Alle Inhalte (Namen, Zahlen, Adressen, Telefonnummern) sind frei erfunden.
